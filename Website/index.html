VCCに追加する方法

  1. 01

    VCCを開き、Settings を選択します。

  2. 02

    Packages タブで Add Repository を選択します。

  3. 03

    下のURLを貼り付け、Add を選択します。

  4. 04

    内容を確認し、I Understand を選択します。
